AI FILE INSPECTOR - REACT + DJANGO PORTAL

Open Start Portal.bat (or Start Inspector.bat).
The browser opens http://127.0.0.1:8000. Keep the server window open.
For a new computer, install Python 3.12 x64 and Node.js 22.12 or newer,
then run Setup Windows.bat first.

See README.md for setup, percentages, model details and training requirements.
See FILE-LIMITS.txt for accepted file types and limits.

The AI-like percentage is the share of checked sections flagged AI-like,
weighted by their length. It is not proof of how many words AI wrote.
The current Gradient model weights are unchanged.
