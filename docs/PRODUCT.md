# AI File Inspector
Local Windows writing/file inspection tool for a user and teammate checking mixed types of writing. Main interaction is upload or paste, then read a clear result. React owns the portal and report UI; Django owns upload validation, session-scoped jobs, model inference and storage. No public hosting or cloud document upload is authorized. Preserve Gradient and its tested rules until a separate evaluation supports a weight change. Show a token-weighted share of checked sections flagged AI-like, not a claimed percentage of words authored by AI. Keep uncertainty, partial coverage, errors and file limits visible; technical images and details start closed.
