# Portal design
Extend the existing report identity: warm off-white canvas, forest green text/actions, quiet sage rules, system sans-serif and readable white work surfaces. Operate mode. The task flow is file selection or paste, scan progress, then report. A left rail provides new scan, recent scans and limits; it becomes a top navigation on narrow screens. The main report leads with three equally prominent estimated shares (Human, AI, Uncertain), followed by checked coverage. No decorative imagery. Status labels always include text. All controls have visible focus, disabled/busy/error states and at least 40px target height. Tables and disclosure panels hold technical details. Files and result cards wrap long names. Respect reduced motion. Test desktop and mobile as one bounded inspection round, then correct material defects together.
